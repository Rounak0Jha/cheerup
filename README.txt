FOR YOU — NOTES GIFT VERSION
============================

This version includes the uploaded handwritten-notes PDF as a downloadable gift.

SITE FLOW
---------
1. Enter
2. "Someone admires you."
3. Encouragement message
4. "There's a little gift for you"
5. Download handwritten notes

PDF
---
The included file is:
assets/PPS_HANDWRITTEN_NOTES.pdf

The DOWNLOAD YOUR NOTES button downloads it as:
PPS-Handwritten-Notes.pdf

The "view them first" link opens the PDF in a new browser tab.

MUSIC
-----
Add your own permitted MP3 as:
assets/music.mp3

The music starts after the visitor presses ENTER because browsers commonly
block audio autoplay before user interaction.
